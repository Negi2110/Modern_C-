```cpp
// ============================================================
// INLINE VARIABLES (C++17), STATIC MEMBERS - INTERVIEW NOTES
// ============================================================

// ============================================================
// SECTION 1: THE PROBLEM BEFORE C++17
// ============================================================

// BEFORE C++17 - static member variables needed TWO places:
//
// struct.hpp:
// struct Struct {
//     static int SomeValue;   // DECLARATION only (no storage)
// };
//
// struct.cpp:
// int Struct::SomeValue = 10;  // DEFINITION (creates actual storage)
//
// WHY TWO PLACES?
// -> ONE DEFINITION RULE (ODR)
// -> .hpp included by multiple .cpp files
// -> if definition was in .hpp -> multiple copies -> LINKER ERROR
// -> solution: declare in .hpp, define ONCE in exactly ONE .cpp
//
// YOUR COMMENTED CODE:
// // int Struct::SomeValue = 10;  <- this was in struct.cpp
// -> needed before C++17 to create storage for the static member
// -> C++17 inline static makes this unnecessary!

// ============================================================
// SECTION 2: THREE WAYS TO INITIALIZE STATIC MEMBERS
// ============================================================

// struct.hpp:
#pragma once

struct Struct
{
    // WAY 1: static const int (traditional, integer types only)
    // static const int SomeValue = 8;
    // -> can initialize IN-CLASS for INTEGRAL types only
    // -> float/double/string: NOT allowed in-class with this syntax
    // -> still needs out-of-class definition in .cpp if ODR-used:
    //    const int Struct::SomeValue;  // in .cpp (no initializer)
    // -> "ODR-used" = address taken OR referenced in certain contexts

    // WAY 2: inline static int (C++17 - your main example)
    // inline static int SomeValue = 127;
    // -> inline keyword on variable (C++17 feature)
    // -> CAN be initialized IN-CLASS
    // -> DOES NOT need out-of-class definition
    // -> works for ANY type (int, float, string, custom class)
    // -> compiler handles storage automatically (like inline function ODR)
    // -> YOUR COMMENT: "after inline static you don't have to complete extra header"
    //    CORRECT: no separate .cpp definition needed!

    // WAY 3: static constexpr (C++11/17 - your ACTIVE code)
    static constexpr int SomeValue = 127;
    // -> constexpr implies COMPILE TIME constant
    // -> constexpr implies inline in C++17 (no out-of-class def needed)
    // -> BEST for compile-time constants (replaces #define completely)
    // -> type safe, scoped, debugger visible
    // -> value baked into binary at compile time
    // -> most PREFERRED for constant values
};

// ============================================================
// SECTION 3: HOW INLINE VARIABLE WORKS (C++17)
// ============================================================

// "How does inline work?" - YOUR QUESTION
//
// INLINE VARIABLE tells the linker:
// "Multiple definitions of this variable exist (one per .cpp that
//  includes this header) but they are ALL THE SAME - pick one"
//
// WITHOUT inline static:
// main.cpp includes struct.hpp -> creates Struct::SomeValue
// other.cpp includes struct.hpp -> creates ANOTHER Struct::SomeValue
// LINKER: TWO definitions! ERROR!
//
// WITH inline static:
// main.cpp includes struct.hpp -> creates Struct::SomeValue (marked inline)
// other.cpp includes struct.hpp -> creates ANOTHER (marked inline)
// LINKER: both marked inline, guaranteed identical -> picks ONE, merges
// No error!
//
// SAME mechanism as inline FUNCTIONS:
// inline function in header: each .cpp gets a copy, linker merges them
// inline variable in header: each .cpp gets a copy, linker merges them

// ============================================================
// SECTION 4: YOUR COMMENT - IMPLICIT inline IN CLASS
// ============================================================

// YOUR COMMENT:
// "inline specifier when used in function, declares function to be an
//  inline function. A function defined entirely inside a class/struct/union
//  definition, whether a member function or non-member friend function,
//  is implicitly an inline function unless attached to a named module"
//
// THIS MEANS:
// struct Foo {
//     void bar() { std::cout << "hi"; }  // IMPLICITLY inline!
//     // ^ defined inside class body = inline by default
// };
//
// vs
//
// struct Foo {
//     void bar();  // NOT inline (just declared here)
// };
// void Foo::bar() { std::cout << "hi"; }  // defined outside - NOT inline

// ============================================================
// SECTION 5: COMPLETE COMPARISON TABLE
// ============================================================

// | Syntax                          | Type   | In-class init | .cpp needed | Notes          |
// |---------------------------------|--------|---------------|-------------|----------------|
// | static int x;                   | any    | NO            | YES         | pre-C++17 way  |
// | static const int x = 5;        | int    | YES (int only)| maybe       | ODR-use rules  |
// | static constexpr int x = 5;    | any*   | YES           | NO (C++17)  | BEST for const |
// | inline static int x = 5;       | any    | YES           | NO          | C++17 mutable  |
// | inline static const int x = 5; | any    | YES           | NO          | C++17 const    |
//
// *constexpr requires compile-time constant expression as initializer

// ============================================================
// SECTION 6: PRACTICAL USE CASES
// ============================================================

// USE static constexpr for CONSTANTS:
// struct Config {
//     static constexpr int MAX_ENTITIES = 1000;
//     static constexpr float TICK_RATE = 60.0f;
//     static constexpr char* VERSION = "1.0";  // ERROR: char* not literal
//     static constexpr std::string_view VERSION = "1.0";  // OK (C++17)
// };
// Config::MAX_ENTITIES  // 1000, compile-time, no .cpp needed

// USE inline static for MUTABLE shared state:
// struct Logger {
//     inline static int instanceCount = 0;  // shared counter
//     Logger() { instanceCount++; }
//     ~Logger() { instanceCount--; }
// };
// Logger::instanceCount  // runtime value, shared across all instances

// USE in YOUR ISSST context:
// struct DISConfig {
//     static constexpr int DEFAULT_PORT = 3000;
//     static constexpr int MAX_PDU_SIZE = 1500;  // MTU
//     inline static std::string multicastAddress = "239.255.0.1";
// };
// DISConfig::DEFAULT_PORT  // 3000, no .cpp needed!

// ============================================================
// SECTION 7: main.cpp TRACE
// ============================================================

#include <iostream>
// #include "struct.hpp"  (shown above)

int main()
{
    Struct s;
    // creates Struct object (empty, no instance data)
    // Struct has NO non-static members!
    // s is essentially useless here (SomeValue is static, belongs to class)

    // Struct::SomeValue = 89;  // COMMENTED OUT
    // -> would be ERROR anyway: SomeValue is constexpr (const, read-only)
    // -> could only assign if it were: inline static int (non-const)

    std::cout << Struct::SomeValue << '\n';
    // ACCESS via class name (not via object, because it's static)
    // Struct::SomeValue = 127 (constexpr value)
    // prints: 127

    return 0;
}

// OUTPUT: 127

// SECTION 8: INTERVIEW QUESTIONS
// ============================================================

// Q1: What is an inline variable (C++17)?
//     -> A variable (typically static member) that can be defined
//        in a header file without violating ODR. Linker treats multiple
//        identical definitions as one. Eliminates need for separate
//        .cpp definition of static members.

// Q2: What is the difference between static const and static constexpr?
//     -> static const: const value, initialization allowed in-class for
//        integral types only. May need out-of-class definition if ODR-used.
//        static constexpr: compile-time constant, any literal type,
//        implicitly inline in C++17 (no .cpp definition needed).

// Q3: What is the difference between inline static and static constexpr?
//     -> inline static: runtime variable (can be modified), defined in header
//        without .cpp, any type, C++17.
//        static constexpr: compile-time constant (read-only), any literal type,
//        implicitly inline C++17, preferred for constants.

// Q4: Why did static member variables need two definitions before C++17?
//     -> ODR: definition in .hpp = multiple copies = linker error.
//        Solution was: declare in .hpp, define ONCE in .cpp.
//        C++17 inline static eliminates this requirement.

// Q5: What does it mean to "ODR-use" a static const member?
//     -> Taking its address, binding to a reference, or passing to a
//        function that takes by reference. These require actual storage.
//        Simple reads of constexpr values don't ODR-use them (they're
//        substituted as literals at compile time).

// Q6: When are member functions implicitly inline?
//     -> When defined INSIDE the class/struct/union body.
//        Out-of-class definitions (ClassName::method) are NOT inline.
//        Applies to both member functions and non-member friend functions
//        defined inside a class.

// Q7: Can static constexpr work with non-integer types?
//     -> YES for literal types: float, double, bool, char, enums,
//        std::string_view (C++17), custom types with constexpr constructor.
//        NOT for: std::string, std::vector (require heap allocation).

// Q8: Why prefer static constexpr over #define for class constants?
//     -> constexpr: type-safe, scoped (Struct::SomeValue), debugger visible,
//        respect access control (can be private).
//        #define: no scope, no type, no encapsulation, can conflict with names.
```

**Three static member styles - which to use when:**

```cpp
struct Config {
    // CONSTANT known at compile time → static constexpr (BEST)
    static constexpr int MAX_SIZE = 100;    // no .cpp needed (C++17)

    // MUTABLE shared state → inline static (C++17)
    inline static int instanceCount = 0;    // no .cpp needed, changeable

    // PRE-C++17 way → requires .cpp definition
    static int legacyValue;                 // .cpp: int Config::legacyValue = 0;
};
```

**The ODR problem and its solution:**

```
BEFORE C++17:                      C++17 INLINE:
struct.hpp:                        struct.hpp:
  static int x;  ← declare only     inline static int x = 10;  ← complete!

struct.cpp:                        struct.cpp:
  int Struct::x = 10;  ← NEEDED     (nothing needed!)

YOUR COMMENT: "after inline static you don't have to complete extra header"
→ means: no extra .cpp definition required
```

> **The interview soundbite**: Before C++17, static member variables needed a *declaration* in the `.hpp` and a *definition* in exactly one `.cpp` — separating intent from storage. C++17's `inline static` and the implicit inlining of `static constexpr` collapsed this into a single header-only declaration, eliminating an entire category of "where's the definition?" linker errors.
